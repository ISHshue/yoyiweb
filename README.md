# yoyiweb — 佑鎰企業形象網站

公開網站：https://ishshue.github.io/yoyiweb/

靜態 HTML、CSS 與 JavaScript，透過 GitHub Pages 的 main 分支根目錄發布，不需安裝套件或建置。

## 網站內容

- 佑鎰介紹、CNC 加工服務、真實加工影片、工件展示與 Instagram 聯絡。
- 標題為思源宋體字形，內文為台北黑體字形；字型由本站提供。
- 原創佑鎰 SVG 圖標、頁面與影片載入動畫、手機導覽與減少動態效果支援。

## 素材與授權

- 加工內容與遠端 YouTube 縮圖：[CNC 阿寬／佑鎰](https://www.youtube.com/@yo-yi)。影片以 YouTube 官方隱私加強播放器嵌入，未重新託管影片。
- Instagram：[trontalshue](https://www.instagram.com/trontalshue/)。
- 思源宋體：[Adobe Source Han Serif](https://github.com/adobe-fonts/source-han-serif)，授權見 fonts/SourceHanSerif-OFL.txt。
- 台北黑體：[JT Foundry](https://sites.google.com/view/jtfoundry/zh-tw/downloads)，[WOFF2 封裝來源](https://github.com/vp-tw/cjk-web-fonts/tree/main/packages/taipei-sans-tc)，授權見 fonts/TaipeiSans-OFL.txt。
- 字型已精簡為網站使用字集，保留原字形及授權，內部名稱為 Yo Yi Serif Web／Yo Yi Sans Web。新增文字時須重新產生字集；來源網址記錄於 fonts/sources.json。
- Dot spinner：使用者提供的 Uiverse.io / abrahamcalsin 動畫，原始作者註記保留於 loader.css。

本站不宣稱擁有第三方影片、字型或社群內容的權利。
